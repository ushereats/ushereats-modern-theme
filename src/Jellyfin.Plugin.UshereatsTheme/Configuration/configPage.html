Before it draws anything, Jellyfin asks the server several things one after another (server info, your account...): over the internet each one is a wait. Each device keeps the answers from last time and opens with them at once, fetching fresh ones in the background for next time. Off: the kept answers are cleared.
Speed test

Tests the whole site: times every kind of server request (3 times each), lists what each plugin adds to every page, then opens every page in a frame (everything in the header, every library, a movie, a show, a season, an episode, a person, a collection, music, playlists, search, favourites, your settings, the dashboard) and times when each part appears, freezes, layout jumps, the slowest files and whose they are. Meanwhile the server records every request it answers (Jellyfin's and every plugin's) with how long it took, plus CPU and memory, and the scheduled tasks are listed with how long they last took. Takes 1–3 minutes: don't touch anything. Then copy the results and send them.

Server settings

Everything set in the dashboard, as plain text you can copy and paste anywhere: server info, general settings, every library with its options and folders, playback and transcoding, networking, metadata, branding, scheduled tasks, plugin repositories and every installed plugin with its settings. Passwords, keys and tokens are replaced with [hidden]. Users are counted, not listed.
