Ushereats Theme

Changes apply on the next page reload. Needs File Transformation. SleekFin is built in: its settings (header, details pages, cards, hero look) are on the Ushereats Theme: Look page. Uninstall the separate SleekFin plugin.

Accent colour

One colour for the whole UI: buttons, progress bars, stars, highlights, glows.

Speed & feel

Background colour cross-fades when it changes. Off = instant. (The first one is always instant.)

Home banner (SleekFin's look), loads instantly. Turn SleekFin's own hero off.

Greeting + sound once per session after sign-in.
Soft colour from the hero / hovered card behind every page.
Info overlay when hovering posters (mouse only).
4K / Dolby Vision / HDR chips on posters.
Time left badge on Continue Watching.

New episode / new season tags.
